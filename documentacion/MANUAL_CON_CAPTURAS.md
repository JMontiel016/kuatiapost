# Manual con capturas

Se incorporaron las nueve imágenes proporcionadas, recortando solo el área de trabajo para mejorar la lectura. No se alteraron datos ni controles. Las zonas numeradas son interactivas en la guía web; el PDF conserva los recuadros y las leyendas. Las imágenes pueden ampliarse desde el manual.

Se retiró el apartado del asistente del menú y de la guía. Sus archivos internos no se invocan desde el menú.

Fuente del contenido: components/manual/contenido-manual.json. Guía web: components/manual/ManualUso.tsx. Capturas: public/manual/capturas. Manual descargable: public/manual/KuatiaPost-Manual-de-Uso.pdf.

Comprobaciones: TypeScript y compilación con Webpack. El motor predeterminado no pudo utilizar el enlace externo de dependencias de este entorno; no se cambió el script del proyecto. PDF de 27 páginas revisado visualmente. No se realizaron envíos a integraciones externas.
