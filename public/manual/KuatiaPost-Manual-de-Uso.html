Manual de uso de KuatiaPost

Edición 1 de octubre de 2026. Guía interactiva sin datos reales ni credenciales.

Envío de datos

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. Elegí Factura, Nota de crédito, Nota de débito, Remisión o Autofactura. Cada plantilla ofrece sus propios campos.
  2. Completá establecimiento y punto de expedición con tres dígitos y la numeración con siete. Los ceros iniciales se conservan.
  3. Los campos con * son obligatorios para la selección actual. Otro abre una descripción para explicar el valor elegido.
  4. Seleccioná contribuyente o no contribuyente. La operación local utiliza Paraguay; servicios al exterior necesita otro país.
  5. En contado agregá pagos. Cheque abre número y banco; tarjeta abre marca y procesamiento. Agregá productos con Añadir producto.
  6. El JSON es editable: las propiedades adicionales se conservan. Revisá los campos antes de enviar; la aceptación procede del servicio configurado.

Configuración y token

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. Indicá por separado las URL de token, envío, consulta y KUDE. Si consulta y KUDE usan la misma URL, activá la casilla correspondiente.
  2. Ingresá Usuario y Contraseña. El ojo permite ver la contraseña; el JSON permanece oculto hasta pulsar Ver y editar JSON.
  3. El JSON inicia con ruc y password. Podés modificarlo y añadir propiedades; Usuario y Contraseña se sincronizan cuando la sintaxis es válida.
  4. Generar token realiza la solicitud a tu servicio. El token obtenido se usa en envíos y consultas. Podés verlo, reemplazarlo o eliminarlo.
  5. Las credenciales permanecen en esta pestaña mientras trabajás. Recargar o cerrar inicia una sesión vacía. No existe conservación por 24 horas.

Consulta y KUDE

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. Elegí el tipo de operación y completá establecimiento, punto de expedición y numeración. Estos valores se reflejan inmediatamente en el JSON.
  2. Consultá el estado con la URL configurada y el token de esta sesión. Una respuesta HTTP correcta por sí sola no significa aprobación.
  3. Obtener KUDE espera un PDF codificado en base64. Cuando el servicio lo devuelve correctamente, podés visualizarlo y descargarlo.
  4. Podés editar por separado el JSON de consulta y el del KUDE. No se agrega ticket automáticamente.

Importación, revisión y exportación

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. Importar archivo admite JSON, TXT con contenido JSON o XML, XML con un único DE y Excel .xlsx. No se admite el antiguo formato .xls.
  2. El XML DE se importa sin firmar ni emitir. Revisá los campos del servicio: el esquema XML y el contrato JSON de tu integración pueden diferir.
  3. Excel debe usar las hojas exportadas por KuatiaPost: Cabecera y grupos como Detalles o Pagos. Se conserva un respaldo JSON. No se ejecutan fórmulas.
  4. Revisar muestra todos los problemas detectados y permite minimizar la lista. Corregí el campo señalado; los errores de conexión son diferentes de los errores de datos.
  5. JSON y TXT conservan la solicitud. Excel exporta un único registro. XML exporta el formato de intercambio KuatiaPost: no es un XML fiscal firmado.
  6. La respuesta del servicio se puede minimizar y desplegar. Los avisos desaparecen después de unos segundos: verde indica una acción correcta, amarillo una revisión pendiente y rojo un fallo.

Crear NC desde XML

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. Seleccioná Crear NC desde XML e importá el XML de la factura de origen. Se conserva el archivo para revisar la conversión.
  2. Completá el establecimiento, punto de expedición y numeración de la nueva nota; no se toman como valores predeterminados los de la factura original.
  3. Para una nota parcial seleccioná los códigos de producto y luego la cantidad o el monto. El sistema recalcula los totales a partir de los valores originales.
  4. Si el monto no puede representarse exactamente con la precisión admitida, se indica el problema para que ajustes el valor; no se inventa otra cantidad.
  5. Revisá el JSON generado y usalo en Envío de datos. Convertir no envía ni aprueba la operación.

Asistente

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. Este apartado muestra Próximamente habilitado en KuatiaPost. No consulta proveedores ni consume cuotas.
  2. Las ayudas junto a cada campo explican las reglas implementadas de forma local. Podés abrirlas y cerrarlas sin salir del formulario.

Tema oscuro y sesión

Vista esquemática del programa. Pulsá un recuadro para identificar su función.

Seleccioná una zona de la vista.

  1. El botón de luna, arriba a la derecha, activa el tema oscuro. En ese tema, el botón de sol recupera el tema claro sin modificar los datos.
  2. Cambiar de apartado conserva los borradores. Recargar o cerrar borra datos, token y respuestas de la sesión. Cada pestaña tiene su propia memoria.
  3. Los archivos descargados quedan en tu equipo hasta que los elimines. El servicio externo al que enviás puede conservar solicitudes según su propio funcionamiento.
  4. El Asistente permanece anunciado como Próximamente habilitado en KuatiaPost; no realiza consultas a proveedores.
